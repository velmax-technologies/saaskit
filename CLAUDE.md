# SaaSKit Repository Instructions

Read and follow the project-specific development guidelines in
`app/CLAUDE.md` for all work in this repository.

## Laravel Boost

- Use the configured Laravel Boost MCP server when its tools are relevant.
- Consult version-appropriate Laravel documentation for framework-specific changes.
- Follow the selected Laravel, testing, and Tailwind skills when relevant.

## Repository safety

- Run application commands through the documented Docker Compose workflow.
- Preserve unrelated changes and untracked files.
- Never expose or commit environment secrets.
- Do not stage, commit, revert, or delete files without explicit approval.
